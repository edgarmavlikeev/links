# Сайт-визитка Эдгара Мавликеева

Готовый статический сайт. Сборщик, установка зависимостей и внешние библиотеки не нужны.

## GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория: index.html, style.css, script.js и папку assets.
2. Откройте Settings → Pages.
3. В Source выберите Deploy from a branch, затем ветку main и папку / (root).
4. Сохраните настройки. GitHub покажет адрес сайта после публикации.

Для локального просмотра откройте index.html в браузере. Все пути относительные, сайт работает и в подпапке репозитория. Шрифты системные, фотография хранится локально. JavaScript используется только для часов; все ссылки работают без него. Анимации учитывают настройку уменьшения движения.
